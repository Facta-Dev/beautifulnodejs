# Beautiful Node.js

Agent Skills that teach coding agents to write, review, and port idiomatic Node.js +
TypeScript, with a tested lint configuration. Sibling of beautifulrust / beautifulpython /
beautifulgo.

Skills target **Fastify + TypeScript + Zod + tsyringe + pg/pg-pool + Drizzle ORM +
PgBouncer + BullMQ + Redis + Pino + OpenTelemetry/Prometheus + PM2/Kubernetes** — the
enforced stack — under **hexagonal architecture + vertical slicing**, with the contracts
**unbreakable and non-waivable**.

Skills target Claude Code, OpenAI Codex, GitHub Copilot, Cursor, Gemini CLI, and any
other agent that reads the Skill format.
